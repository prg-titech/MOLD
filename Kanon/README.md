# Kanon source in MOLD

This directory contains the Kanon graph editor source used by the MOLD demo. Kanon originated in [prg-titech/Kanon](https://github.com/prg-titech/Kanon); this copy includes the MOLD integration. Its MIT license is in `LICENSE`.

Build and run the complete demo using the instructions in the [MOLD README](../README.md). The original Kanon project and its independent demo remain at https://prg-titech.github.io/Kanon/ .
